

# Smart Water Irrigation System

## Aim
To automatically water plants based on soil moisture.

## Components
- Arduino Uno
- Soil moisture sensor
- Relay module
- DC water pump
- Jumper wires

## Working
The sensor measures soil moisture.
When the soil is dry, the Arduino switches
on the water pump.
When the soil is sufficiently wet, the
pump switches off.

## Programming Language
Embedded C / Arduino C++

## Applications
- Agriculture
- Home gardens
- Greenhouses
